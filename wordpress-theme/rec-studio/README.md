# REC Studio

## Установка

1. Установите архив `rec-studio.zip` через раздел **Внешний вид > Темы**.
2. Активируйте тему **REC Studio**.
3. При активации автоматически создаются страницы `about`, `projects`, `help`, `news` и `contacts`.
4. Если внутренние страницы возвращают ошибку 404, откройте **Настройки > Постоянные ссылки** и один раз сохраните настройки.

Тема сохраняет интерактивную вёрстку исходного проекта. Содержимое основных экранов находится в PHP-шаблонах темы.
