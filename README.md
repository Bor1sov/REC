# REC Studio — Interactive Landing Experience

Интерактивный лендинг для продакшн-студии с акцентом на анимации, параллакс и кинематографическое появление контента.

---

## ✨ Описание

Проект представляет собой одностраничный сайт с нестандартной логикой взаимодействия:

- Главный экран начинается с минималистичного логотипа в центре
- При первом клике появляется фирменная подпись (**RECSTUDIO PRODUCTION COMPANY**)
- При дальнейшем взаимодействии запускается сцена с параллаксом и контентом
- Пользователь может управлять сценой через скролл или клик

Основная идея — создать ощущение “интро” как в современных студийных сайтах (Awwwards / Apple style).

---

## ⚙️ Функциональность

### 🎬 Интерактивное интро
- Центрированный логотип
- Анимация появления текста слева направо
- Плавный переход в основной интерфейс

### 🖱 Управление сценой
- Скролл управляет прогрессом анимации (`progress`)
- Клик по логотипу повторяет поведение скролла
- Reset состояния по повторному клику

### 🌄 Параллакс
- Фоновое изображение двигается и масштабируется
- Текстовый блок выезжает снизу
- Контент появляется по мере “прокрутки”

### 🧩 UI элементы
- `menu` — боковая навигация
- `settings` — всегда доступные настройки
- `about` — основной контент с blur-эффектом

---

## 🎨 Визуальные особенности

- Кастомный шрифт **Holgada**
- Контрастная тёмная тема
- Большая типографика (hero text)
- Эффект “маски” текста через `background-clip`
- Blur + прозрачность для контентных блоков

---

## 🛠 Технологии

- HTML5
- CSS3 (Flexbox, transitions, backdrop-filter)
- Vanilla JavaScript
- requestAnimationFrame для плавной анимации
